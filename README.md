## 2) Confirm Details
Open `index.html` and confirm:
- Rent: $1,650/month

- Move-in: First month’s rent + security deposit

## 3) Publish for Free on GitHub Pages
1. Create a GitHub account: https://github.com
2. New repository → name it **yourname.github.io**
3. Upload all files (`index.html`, `assets`, `photos`, `robots.txt`, `sitemap.xml`).
4. Your live site will be at: https://yourname.github.io

### Optional
- Update "yourname" in `robots.txt` and `sitemap.xml` to your GitHub username.
- Add a custom domain later if you want.
- Replace the Google Maps links to use your custom domain once live.

## 4) Craigslist & Social
Use `craigslist_post.txt` as ready-to-paste copy. Add your site link and a few photos.
